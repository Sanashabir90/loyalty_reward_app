# Loyalty Rewards Dashboard 🏆

**Overview**
Ek modern, responsive, aur interactive **Loyalty Rewards Dashboard** jo customers ko unki loyalty points track karne aur manage karne ki sahulat deta hai.

**Key Features**
*   **Modern UI:** Glassmorphism design jo user ko ek premium aur clean experience deta hai.
*   **Persistent Data:** `localStorage` ka istemal karte hue points ko browser mein save kiya gaya hai.
*   **Interactive Controls:** Ek simple aur intuitive "Check-in" button, jo clicks par real-time points update karta hai.
*   **Responsive Layout:** Mobile aur desktop screens par perfectly adjust hone wala design.

**Tech Stack**
*   **Frontend:** HTML5, Tailwind CSS
*   **Logic:** JavaScript (State management)
